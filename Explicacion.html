Traductor-Simple: explicación completa del código

Proyecto: traducción bidireccional Español ↔ Inglés mediante HTML, JavaScript, Scala, Python/FastAPI y SWI-Prolog.

La interfaz permite elegir la dirección y traducir archivos .txt, Word moderno .docx y PDF de hasta 10 MB. El resultado se descarga en el mismo formato y con el sufijo -traducido. Los PDF deben contener texto seleccionable; los documentos escaneados requieren OCR y no se admiten. Si la traducción no cabe en las cajas del diseño original, el texto del PDF se reorganiza y puede ocupar páginas de continuación.

Prueba representativa: la frase I AM FIVE YEARS OLD AND MY FRIEND HAS THREE BOOKS conserva los números escritos y produce una traducción similar a:

yo tengo cinco años y mi amigo tiene tres libros

3. Código del navegador: HTML y JavaScript

El usuario elige Español → Inglés o Inglés → Español y escribe en el primer textarea. Al pulsar Traducir, JavaScript envía el texto y la dirección mediante URL codificada. El formulario de archivos acepta .txt, .docx y PDF con texto seleccionable; envía los bytes a Scala por HTTP POST, Scala los reenvía a Python y la interfaz descarga el documento traducido en el mismo formato.

fetch('/traducir?texto=' + encodeURIComponent(texto))
    .then(respuesta => respuesta.json())
    .then(datos => {
        resultado.value = datos.traduccion || '';
    });

encodeURIComponent permite enviar espacios, números, caracteres especiales y acentos. JavaScript solo conoce el puerto 8080; no llama directamente ni a Python ni a Prolog.

4. Código de Scala: gateway principal

Servidor.scala crea dos contextos HTTP:

  • /: entrega el archivo index.html.
  • /traducir: recibe el texto, conserva letras, acentos y números, y llama a Python.

La limpieza ya permite números:

val limpio = texto.toLowerCase
    .replaceAll("[^a-záéíóúñü0-9 ]", "")
    .trim

Scala construye la petición hacia FastAPI usando Java HTTP Client:

val textoCodificado = URLEncoder.encode(texto, "UTF-8")
val url = URI.create(
    s"http://127.0.0.1:5001/traducir?texto=$textoCodificado"
)

HttpRequest.newBuilder(url).GET().build()

Scala devuelve el JSON recibido al navegador. También produce un JSON de error si Python está detenido.

5. Código de Python: procesamiento NLP

FastAPI recibe el texto en servidor.py. El modelo de datos se declara con Pydantic:

class SolicitudTraduccion(BaseModel):
    texto: str

Python selecciona el diccionario y las reglas de frase según la dirección elegida:

  1. Reconocer frases: aplica primero expresiones completas, como large number of → gran cantidad de.
  2. Traducir vocabulario: consulta el diccionario de inglés → español o español → inglés, incluyendo términos de redes y seguridad.
  3. Conservar el texto: mantiene puntuación, mayúsculas y siglas técnicas como TCP, SYN, DoS y DDoS.

Por ejemplo, 23 se conserva como texto y se envía también mediante JSON. Los números escritos tienen su propia entrada: three se convierte en tres y five en cinco.

Los números escritos también están incluidos en el diccionario: zero, one, two, three, four, five, six, seven, eight, nine, ten, eleven, twelve, twenty, thirty, hundred. Por ejemplo, five se convierte en cinco.

El vocabulario incluye términos técnicos como administrator, TCP SYN packets y denial of service, además de proyectos, entregas, trabajo en equipo y negociación, por ejemplo project delay, active listening y reach an agreement. Las reglas ajustan artículos y expresiones completas para reducir traducciones palabra por palabra.

Edad: I am 5 years old se traduce como Yo tengo 5 años; en sentido inverso, Tengo 5 años se traduce como I am 5 years old.

6. Código de Prolog: servidor de reglas

traductor.pl registra el servidor HTTP en el puerto 5002:

:- use_module(library(http/thread_httpd)).
:- use_module(library(http/http_dispatch)).
:- use_module(library(http/http_json)).

:- http_handler(root(traducir), traducir_http,
                [methods([post])]).

El servidor lee el JSON enviado por Python:

http_read_json_dict(Request, Datos),
get_dict(propuesta, Datos, Propuesta),
validar_genero(PropuestaAtoms, PropuestaValidadaAtoms),
reply_json_dict(_{
    traduccion: Resultado,
    reglas_aplicadas: true
}).

Prolog conserva los elementos desconocidos y verifica concordancias definidas por reglas. Los números son datos neutros: se dejan sin modificar dentro de la frase.

7. Ejemplo completo con números

Entrada:     I AM FIVE YEARS OLD AND MY FRIEND HAS THREE BOOKS

Scala:       conserva "i am five years old and my friend has three books"
Python:      tokens = i, am, five, years, old, and, my, friend, has, three, books
Python:      propuesta = yo tengo cinco años y mi amigo tiene tres libros
Prolog:      valida las reglas y conserva los números escritos como palabras
Salida:      yo tengo cinco años y mi amigo tiene tres libros

10. Cómo se usó cada herramienta

  1. sbt compila Scala y ejecuta el gateway en el puerto 8080.
  2. Python ejecuta FastAPI y el procesamiento lingüístico en el puerto 5001.
  3. SWI-Prolog carga el archivo de reglas y abre el servidor HTTP del puerto 5002.
  4. Java HTTP Client permite que Scala consulte FastAPI sin agregar otra biblioteca.
  5. HTTP JSON comunica Python con Prolog.
  6. Navegador y Fetch API envían texto y reciben el resultado final JSON.

ErrorCausa probableSolución

La petición falla en el puerto 5002Prolog no inició el servidor.Usar el comando completo del apartado 9.
